## Assistant Généalogie IA (RAG Local) - v1.0.0

Cette version est un exécutable autonome. Vous n'avez pas besoin d'installer Python, ni aucun autre logiciel de code pour l'utiliser !

### 💻 Comment l'installer et la lancer :
1. Téléchargez le fichier **`Assistant_Genealogie_IA.exe`** situé dans la section **Assets** ci-dessous.
2. Double-cliquez sur l'exécutable pour lancer l'application.

*Note : Au tout premier démarrage, le logiciel peut mettre entre 5 et 10 secondes à s'ouvrir, le temps de charger l'interface graphique en mémoire.*

### 🛠️ Prérequis :
* Système d'exploitation : Windows (64-bit)
* Pour les fonctionnalités de l'IA (en option) : Assurez-vous d'avoir **Ollama** installé et lancé sur votre machine avec le modèle `gemma2:2b`.
